Accessibility Statement

PDFCropper is committed to ensuring digital accessibility for people with disabilities.

Our Commitment

We are committed to providing a website and mobile application that is accessible to the widest possible audience, regardless of technology or ability. We aim to comply with all applicable standards, including the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA.

Accessibility Features

Visual Accessibility

  • High contrast color schemes for better readability
  • Scalable text that can be enlarged up to 200% without loss of functionality
  • Clear visual focus indicators for keyboard navigation
  • Alternative text for all images and icons
  • Consistent navigation and layout across all pages

Motor Accessibility

  • Large touch targets (minimum 44px) for easy interaction
  • Keyboard navigation support for all interactive elements
  • No time limits on user interactions
  • Drag and drop alternatives for cropping functionality

Cognitive Accessibility

  • Simple, clear language throughout the interface
  • Consistent navigation patterns
  • Error messages that clearly explain what went wrong
  • Step-by-step guidance for complex tasks
  • Undo functionality for all major actions

Mobile Accessibility

Our mobile app includes additional accessibility features:

  • VoiceOver (iOS) and TalkBack (Android) support
  • Voice control compatibility
  • Switch control support
  • Adjustable gesture sensitivity
  • Screen reader optimized interface
  • High contrast mode support

Assistive Technology Support

PDFCropper is designed to work with a variety of assistive technologies, including:

  • Screen readers (JAWS, NVDA, VoiceOver, TalkBack)
  • Voice recognition software
  • Keyboard-only navigation
  • Switch devices
  • Magnification software

Ongoing Improvements

We continuously work to improve the accessibility of our services:

  • Regular accessibility audits and testing
  • User feedback integration
  • Staff training on accessibility best practices
  • Collaboration with disability advocacy groups
  • Updates based on evolving accessibility standards

Keyboard Navigation

You can navigate PDFCropper using only your keyboard:

  • Tab: Move forward through interactive elements
  • Shift + Tab: Move backward through interactive elements
  • Enter/Space: Activate buttons and links
  • Arrow keys: Navigate within menus and lists
  • Escape: Close dialogs and menus

Known Issues

We are aware of the following accessibility issues and are working to resolve them:

  • Some third-party embedded content may not be fully accessible
  • Complex PDF cropping interactions may require additional assistive technology support

We are actively working on solutions and expect to address these issues in future updates.

Need Help?

If you encounter any accessibility barriers or need assistance using PDFCropper, please don't hesitate to contact us.
