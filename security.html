Security & Privacy

Your security and privacy are our top priorities. Learn how we protect your data and documents.

100% Local Processing - Zero Data Upload

Data Protection

PDFCropper is designed with privacy-first principles to ensure your documents never leave your device:

  • Local Processing: All PDF cropping and editing happens entirely on your device
  • No Cloud Storage: We never upload, store, or access your documents
  • No Data Collection: Your files and personal information remain completely private
  • Offline Functionality: The app works completely offline after installation
  • Automatic Cleanup: Temporary files are automatically deleted after processing

Mobile Security

iOS Security Features

  • App Sandbox isolation prevents access to other apps' data
  • iOS App Store security review and code signing
  • Secure file handling using iOS security frameworks
  • Face ID/Touch ID integration for app access (optional)
  • Encrypted local storage for app preferences

Android Security Features

  • Android permission model restricts access to device resources
  • Google Play Protect scanning and verification
  • Scoped storage compliance for enhanced privacy
  • Biometric authentication support
  • Runtime permission requests for transparency

Technical Security

Application Security

  • Regular security audits and penetration testing
  • Secure coding practices and code reviews
  • Memory protection and buffer overflow prevention
  • Input validation and sanitization
  • Error handling that doesn't expose sensitive information

Network Security

  • HTTPS encryption for all web communications
  • Certificate pinning for API connections
  • No unnecessary network requests
  • Minimal data transmission (only for app updates and analytics)

User Privacy

We are committed to protecting your privacy:

  • No Personal Data Collection: We don't collect names, emails, or personal information
  • Anonymous Usage Analytics: Only anonymous, aggregated usage statistics (optional)
  • No Tracking: We don't track your behavior or create user profiles
  • No Third-Party Sharing: Your data is never shared with third parties
  • GDPR Compliant: Full compliance with European privacy regulations
  • CCPA Compliant: Compliance with California privacy laws

Important Security Notice

While PDFCropper processes files locally for maximum security, always ensure you're downloading the app from official sources (App Store, Google Play) to avoid malicious versions.

Vulnerability Reporting

We take security vulnerabilities seriously. If you discover a security issue:

  • Please report it responsibly through our security contact
  • Do not publicly disclose the vulnerability until we've addressed it
  • We'll acknowledge your report within 48 hours
  • We'll provide regular updates on our progress
  • We may offer recognition for valid security reports

Security Updates

We regularly update PDFCropper to maintain the highest security standards:

  • Automatic security updates through app stores
  • Regular dependency updates and security patches
  • Proactive security monitoring and threat assessment
  • Compliance with latest platform security requirements

Certifications & Compliance

  • SOC 2 Type II compliance (in progress)
  • ISO 27001 security management standards
  • OWASP Mobile Security guidelines
  • Platform-specific security certifications (iOS, Android)

Security Concerns?

If you have any security concerns or questions about how we protect your data, please contact our security team.
